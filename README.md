# Food Ordering Management System

## About the Project
A console-based Food Ordering Management System developed using Python. This project allows users to interact with a menu-driven application for food ordering.
## Technologies Used
- Python 3
- Core Python
## Features
- Menu-driven console interface
- Food selection
- Order processing
- Bill calculation
## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the application: python project2.py

- Practiced Python programming fundamentals
- Applied conditional statements and loops
- Improved user input handling and problem-solving skills
